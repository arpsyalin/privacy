Informazioni che trattiamo

生日提醒 / Birthday Reminder, fornita da arpslyl, memorizza i nomi, i compleanni, le scelte del calendario, le note e le impostazioni dei promemoria che inserisci o importi. Anche le preferenze di lingua, tema e visualizzazione sono memorizzate localmente. Non ci sono account, pubblicità o tracciamento a fini di analisi. Non carichiamo sui nostri server né vendiamo i tuoi dati sui compleanni.

Archiviazione e protezione

Le voci sono conservate nello spazio di archiviazione privato dell’app. La versione Android esclude i propri dati dal backup cloud di sistema e dalla migrazione tra dispositivi. Esegui un backup manuale prima di cambiare telefono o disinstallare l’app. L’app non applica una crittografia separata con password ai dati locali o ai file .birthday; proteggi il dispositivo e i file di backup.

Importazione, esportazione e condivisione

L’app legge solo i file che scegli di importare o aprire con essa. L’esportazione e la condivisione avvengono solo su tua richiesta. Un file .birthday contiene le voci selezionate, inclusi nomi, compleanni e note, in formato leggibile. Il servizio di gestione file o l’app destinataria che scegli può conservarlo o trasmetterlo secondo la propria informativa. Condividi solo le voci che hai il diritto di condividere e solo con destinatari fidati. Non possiamo revocare le copie già condivise.

Autorizzazioni e promemoria

Le notifiche sono facoltative e vengono usate per i promemoria locali dei compleanni. I nomi nei promemoria possono apparire sulla schermata di blocco, in base alle impostazioni di sistema. Puoi rifiutare o revocare le notifiche e continuare a gestire le voci. L’autorizzazione all’avvio dopo il riavvio ripristina i promemoria programmati. L’app non richiede accesso a contatti, posizione, fotocamera, microfono, accesso esteso ai file o autorizzazioni per sveglie esatte. Le restrizioni di Android sul consumo della batteria possono ritardare i promemoria.

Conservazione ed eliminazione

Le voci rimangono finché non le elimini. Puoi eliminarle singolarmente oppure usare «Cancella i dati dei compleanni» nella sezione «Il mio» per rimuovere tutte le voci dei compleanni e annullare i relativi promemoria; le preferenze di aspetto e lingua vengono mantenute. Le copie temporanee per l’esportazione o la condivisione vengono eliminate al successivo avvio dell’app o quando cancelli i dati dei compleanni. La funzione di sistema «Cancella spazio di archiviazione» o la disinstallazione rimuove i dati locali dell’app. Le copie esportate in altre cartelle o app devono essere eliminate separatamente. Non è necessario eliminare alcun account, perché non ne viene creato nessuno.

Componenti di terze parti

L’app utilizza componenti per il database locale, la selezione dei file, il pannello di condivisione di sistema, le notifiche e i fusi orari per fornire le proprie funzionalità. Non contiene SDK pubblicitari o di analisi. Aprire il sito dell’informativa o contattarci via e-mail comporta l’uso di servizi esterni all’app; i loro gestori possono trattare informazioni di connessione secondo le rispettive informative. Quando richiedi assistenza, non inviare file di compleanni o altri dati personali, salvo che sia necessario.
